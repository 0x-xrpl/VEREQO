# VEREQO — one-page event positioning (internal working draft)

## One-liner

A proof-aware authorization and consequence instrument for AI agents operating on Injective's financial infrastructure.

## Customer / job

An operator or liquidity provider delegates a narrow set of orders to an AI Agent, but must protect confidential mandates and be able to revoke access without losing visibility of existing financial exposure.

## Why it matters

A proof is not authorization; a connected wallet is not a mandate; a successful transaction is not a filled order. Delegated AI needs an inspectable bridge between confidentiality, policy and execution.

## Differentiation

Order-specific Issuer authorization, real Groth16 local foundation, bounded ActionGate, deterministic disclosure admission and a causal Consequence Space, integrated as one White Instrument. **Only claim components as implemented if the release HEAD and evidence confirm them.**

## Why Injective

Native Spot/Derivative markets, EVM-to-Exchange Precompile, subaccounts, and an AI-finance-focused ecosystem make actual financial semantics possible. Market/custody compatibility must be verified for the live Testnet revision.
